v56: 类型位置也让位 + 自动配对括号/引号

1) 让位补上「类型位置」
   `Dim x As ` / `Set c = New ` 之后 VBE 会弹类型列表，跟我们的弹窗撞在同一处，
   之前只在 `标识符.` 之后让位。engine.vbe_list_expected 拆成两部分：
   - vbe_member_list_expected：`标识符.` 之后输入成员名；
   - _in_type_list_position：`As ` / `New ` 之后填类型名（大小写不敏感，
     注释 / 字符串里不算）。
   同样只在轮询自动触发时拦，手动 Ctrl+Space 照弹，名字打完立刻恢复。

2) 自动配对：敲 `(` 补 `)`、敲 `"` 补另一个 `"`，光标停在中间
   查证过 VBE 原生【不会】自动闭合括号 / 引号（VBE_Extras、Rubberduck 都把它
   当增强功能往外加），所以由我们补不会双份；VBE 只在行尾按回车时补缺失的右引号，
   与逐字符输入不冲突。

   细节：
   - `"` 是既开又闭的一个键：按【光标左边引号数的奇偶】决定补一个（字符串里
     收尾）还是补一对；右边紧邻就是引号时只"跨过去"，一个字符都不写。
   - 注释里 / 有选区 / COM 出错 -> 一律【放行】按键让 VBE 原生处理。
   - 按键 -> 字符用 MapVirtualKey 问当前键盘布局，不写死 vk；排除小键盘。
   - 刻意【同步】写：吞键不可撤销，必须先确知写成功了才吞（与 Shift+Enter 的
     "先吞再 post"不同 —— 丢一个 `(` 比丢一个回车严重）。
   - 顺带把 get_context 的"显示列 -> 字符列"抽成 _caret_char_col()，与写回后
     摆光标共用同一套列语义。
   开关：VBECOMPLETE_NO_AUTOPAIR=1。
